# 분수 탐험대: 분수 곱셈 게임

칸을 색칠하고 겹치는 부분을 세어 분수의 곱셈을 익히는 한국어 웹 게임입니다.

## 플레이

[게임 열기](https://bnuedusgml0507-jpg.github.io/fraction-multiplication-grid/)

첫 번째 분수는 열, 두 번째 분수는 행을 색칠합니다. 진한 초록색으로 겹치는 칸이 곱의 분자이고, 전체 칸 수가 분모입니다. 답은 약분하거나 그대로 입력할 수 있습니다.

## 실행

저장소의 `index.html`을 브라우저에서 열면 됩니다. 빌드 도구나 설치 과정은 필요하지 않습니다.

## 배포

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 GitHub Pages에 자동 배포합니다.

Pages deployment uses the GitHub Actions source configured for this repository.
